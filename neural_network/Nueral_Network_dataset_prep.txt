Neural Network Dataset Preparation

For the Neural Network, we used the optimised gait generated by the Genetic Algorithm in Part 1 of the coursework. The gait was saved in `best_gait_matlab.csv` and contains 300 frames, each with 24 joint angles representing the spider's eight legs.

To prepare the data for training, each frame was converted into an input-output pair. The inputs consist of two values, calculated using the sine and cosine of the frame's position within the walking cycle. This allows the network to recognise the repeating nature of the spider's movement, including the transition between the end and beginning of each cycle. The expected output is a set of 24 joint angles, measured in radians, corresponding to that frame.

The dataset was shuffled using a fixed random seed of 42 so that the results could be reproduced. It was then divided into three sets: 70% for training (210 frames), 15% for validation (45 frames) and 15% for testing (45 frames). The training set is used to teach the network, the validation set helps assess its performance during development, and the test set is reserved for evaluating the final model.

We also implemented checks to ensure that the dataset contains the correct number of frames and joint angles, that all values are finite, and that the joint angles remain within the permitted limits. Automated tests were used to check the dataset structure, input features, reproducibility and separation of the three sets. All eight dataset tests passed successfully.

One limitation is that the dataset was generated from a single optimised GA gait. As a result, the network is being trained to reproduce different phases of that particular walking pattern rather than learning to generate entirely new gaits. Although this is suitable for evaluating how well the network approximates the GA-generated movement, further training data would be needed to assess its ability to generalise to other walking patterns.
