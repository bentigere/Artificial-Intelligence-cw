# Neural Network Architecture and Backpropagation

## 1. Neural Network Architecture

The neural network was implemented using Python and NumPy to predict the 24 joint angles required for the spider's movement.

The network uses a 2 → 64 → 128 → 64 → 24 architecture, consisting of an input layer, three hidden layers and an output layer.

The two inputs represent the sine and cosine of the spider's position in its walking cycle. This allows the network to represent the walking cycle continuously.

The hidden layers contain 64, 128 and 64 neurons. These layers allow the network to learn relationships between the walking cycle and the joint angles. The middle layer has more neurons to provide additional capacity for learning these relationships.

The output layer contains 24 neurons, representing the three joint angles for each of the spider's eight legs.

## 2. Activation Functions

The Rectified Linear Unit (ReLU) activation function was used in the hidden layers.

ReLU outputs zero for negative inputs and keeps positive inputs unchanged. It was chosen because it is simple to implement and allows the network to learn non-linear relationships.

The output layer uses a linear activation because the network needs to predict continuous joint-angle values rather than values restricted to a particular activation range.

## 3. Loss Function

Mean Squared Error (MSE) was used to measure the difference between the predicted joint angles and the target angles.

MSE calculates the average squared difference between predictions and targets. It was chosen because this is a regression problem where the network predicts continuous numerical values.

A lower MSE indicates that the predicted joint angles are closer to the target values.

## 4. Backpropagation

Backpropagation was implemented manually using NumPy rather than relying on a prebuilt neural network framework.

During training, the network first performs forward propagation to calculate its predictions. The MSE loss is then calculated by comparing these predictions with the target joint angles.

Backpropagation uses the chain rule to calculate how each weight and bias contributes to the loss. These gradients are used to update the network parameters through gradient descent.

The aim is to reduce the prediction error over repeated training iterations.

## 5. Testing and Validation

Unit tests were written to check the network's output dimensions, weight shapes and ability to reduce training loss.

Numerical gradient checking was also implemented to verify the backpropagation calculations. This compares the gradients calculated by backpropagation with gradients estimated using small changes to the network parameters.

Gradient checks were performed on the network's layers, weights and biases.

The tests passed, providing evidence that the network's forward propagation and backpropagation implementations work correctly.

## 6. Design Decisions and Limitations

The network was implemented using NumPy to demonstrate an understanding of neural network calculations, particularly forward propagation, backpropagation and gradient descent.

The chosen architecture provides several hidden layers for learning the relationship between gait phase and joint angles, although a smaller network may also be sufficient for this dataset.

One limitation is that the network is trained using frames from a single gait generated by the genetic algorithm. Therefore, successful predictions on the validation data demonstrate performance on unseen phases of that gait, rather than generalisation to completely new walking patterns.

Another limitation is that the linear output layer does not automatically enforce the spider's joint-angle limits. Predicted angles must therefore be checked to ensure they remain within valid bounds.
