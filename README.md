## Part 1: Genetic Algorithm

### Overview

The Genetic Algorithm (GA) generates an optimised walking gait for an eight-legged spider.

Each chromosome contains 7,200 genes, representing 300 frames with 24 joint angles per frame.

The GA uses tournament selection, arithmetic blend crossover and smooth mutation to improve candidate gaits. The fitness function penalises movement errors, allowing better-performing gaits to be selected over generations.

### GA Configuration

| Parameter         | Value                     |
| ----------------- | ------------------------- |
| Population size   | 20                        |
| Generations       | 100                       |
| Tournament size   | 3                         |
| Mutation rate     | 0.1                       |
| Mutation strength | 0.15                      |
| Elitism           | Best chromosome preserved |
| Random seed       | 42                        |

### Running the Genetic Algorithm

From the project root, run:

```bash
python -m genetic_algorithm.main
```

Alternatively, using uv:

```bash
uv run python -m genetic_algorithm.main
```

**Note:** Running the GA again overwrites `data/best_gait_matlab.csv` and `data/fitness_history.csv`. The final Neural Network was trained using the existing GA output.

### GA Results

The GA improved fitness over 100 generations.

| Metric                | Generation 1 | Generation 100 |
| --------------------- | -----------: | -------------: |
| Best fitness          |    -150.0052 |       -35.0511 |
| Average valid fitness |    -176.2865 |       -36.2288 |

Higher fitness is better. Scores are negative because the fitness function subtracts movement penalties.

The best fitness never decreased during the recorded experiment because elitism preserves the highest-scoring chromosome.

### Output Files

- `data/best_gait_matlab.csv` - Optimised walking gait, containing 300 frames and 24 joint angles.
- `data/fitness_history.csv` - Best and average fitness scores across generations.

### MATLAB Animation

1. Open the project folder in MATLAB.
2. Run `ga_main.m`.
3. Observe the optimised gait animation.

The MATLAB animation visualises spider joint movements with a fixed body. It does not simulate physical forward movement.

## Part 2: Neural Network

### Overview

The Neural Network learns to reproduce the optimised gait generated by the Genetic Algorithm.

The network uses a 2-64-128-64-24 architecture with ReLU hidden layers and a linear output layer. It is trained using NumPy, mean squared error and backpropagation.

The GA-generated gait in `data/best_gait_matlab.csv` is used as the training target.

### Final Neural Network Files

- `data/nn_final_model.npz` - Final trained Neural Network model.
- `data/nn_final_history.csv` - Final training history.
- `data/nn_final_info.json` - Training configuration and evaluation information.
- `data/nn_final_gait.csv` - Raw Neural Network predictions.
- `data/nn_final_smoothed_gait.csv` - Smoothed Neural Network predictions.

### Training and Evaluation

The final experiment used 2,000 epochs with a learning rate of 0.001, batch size of 32 and random seed of 42.

The dataset was divided into 70% training, 15% validation and 15% testing.

Final evaluation results:

| Metric         |          Result |
| -------------- | --------------: |
| Training MSE   | 0.00490353 rad² |
| Validation MSE | 0.00543094 rad² |
| Test MSE       | 0.00511563 rad² |
| Test MAE       |  0.05726265 rad |

The complete evaluation and comparison are documented in `neural_network/evaluation_report.md`.

### MATLAB Animation

The animation displays spider joint movements using the same geometry as the GA animation. It does not simulate physical forward movement.

### Gait Smoothing

The raw Neural Network predictions are smoothed using an 11-frame periodic moving average.

To regenerate the smoothed gait in MATLAB, run:

```matlab
test_periodic_smoothing
```

To validate the smoothed gait, run:

```matlab
validate_smoothed_gait
```

Smoothing reduced gait roughness by 65.23% in the final full-cycle comparison.
